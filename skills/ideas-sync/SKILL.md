---
name: ideas-sync
description: Share one ideamine archive between all your machines through an ideamine server, or show the state of the sync. "off" turns it off. The ideamine hook answers this with no model call.
argument-hint: "[url|off]"
disable-model-invocation: true
---

The ideamine hook did not answer this command, and only the hook or the ideamine CLI can change the sync. Tell the user to run `ideamine sync <url>` (or `ideamine sync off`) in a terminal. Then stop.
