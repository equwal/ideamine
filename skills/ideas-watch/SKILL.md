---
name: ideas-watch
description: Turn on the ideamine watcher. Haiku triages each new idea and pairs it with its project, in the background, at almost no cost. "off" turns it off. The ideamine hook answers this with no model call.
argument-hint: "[off]"
disable-model-invocation: true
---

The ideamine hook did not answer this command, and only the hook or the ideamine CLI can run the watcher. Tell the user to run `ideamine watch` (or `ideamine watch off`) in a terminal. Then stop.
